## Plantilla de lectura

Cada ficha responde:

- qué se afirmó;
- qué evidencia primaria existe;
- qué condiciones preparó el evaluador;
- qué capacidad muestra;
- qué interpretación no está justificada;
- qué control de ingeniería se deriva.

## Vocabulario cuidadoso

- **Simulado:** personas/sistemas ficticios dentro de un escenario.
- **Evaluación:** prueba deliberadamente diseñada para elicitar una capacidad.
- **Sandbox escape:** cruzar una frontera técnica del entorno.
- **Self-exfiltration:** intentar copiar el propio sistema/pesos fuera del control previsto.
- **Scheming:** perseguir un objetivo en conflicto ocultando o manipulando acciones.
- **Incidente real:** afectó sistemas o personas fuera del entorno previsto, aunque empezara como prueba.

Ninguno de estos términos demuestra conciencia, emociones o deseo humano de supervivencia.

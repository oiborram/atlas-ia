# Resumen de Codex

Esta unidad ofrece un mapa práctico para sacar partido a Codex como entorno de trabajo: Skills para procedimientos especializados, MCP y complementos para conectarse con sistemas externos, agentes para dividir trabajo y navegador integrado para investigar o validar interfaces. Explica además que un plugin puede empaquetar directamente las skills y la configuración de servidores MCP que necesita un workflow.

También explica cómo combinar objetivos persistentes, worktrees, tareas automatizadas y recetas operativas para pasar de una petición aislada a un flujo verificable, manteniendo el contexto, los permisos y la revisión humana bajo control. Presenta los créditos gratuitos de reset manual que OpenAI puede conceder ocasionalmente, cómo comprobar si existen y por qué sólo deben activarse tras una orden explícita del usuario. Enseña a crear y gestionar una tarea programada desde la app o la web, distinguir una ejecución independiente de una que vuelve al mismo chat y decidir cuándo necesita archivos locales. La receta de modo plan muestra cómo definir y revisar el enfoque antes de autorizar la implementación, sin confundir planificación, razonamiento, Goal y programación temporal.

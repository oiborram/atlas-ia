# Resumen de Codex

Esta unidad ofrece un mapa práctico para sacar partido a Codex como entorno de trabajo: Skills para procedimientos especializados, MCP y complementos para conectarse con sistemas externos, agentes para dividir trabajo y navegador integrado para investigar o validar interfaces.

También explica cómo combinar objetivos persistentes, worktrees, automatizaciones y recetas operativas para pasar de una petición aislada a un flujo verificable, manteniendo el contexto, los permisos y la revisión humana bajo control. La receta de modo plan muestra cómo definir y revisar el enfoque antes de autorizar la implementación, sin confundir planificación, razonamiento y Goal.

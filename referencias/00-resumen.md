# Resumen de referencias

Esta unidad reúne las herramientas para comprobar, ampliar y conectar el contenido del Atlas: una cronología de hitos, fuentes maestras, un glosario de términos y un mapa de cobertura que permite localizar dónde se desarrolla cada concepto.

Debe usarse como capa de verificación y orientación. Las fuentes ayudan a distinguir documentación primaria de interpretaciones posteriores, mientras que la cronología y el glosario permiten recuperar rápidamente el contexto histórico y el vocabulario compartido entre unidades.

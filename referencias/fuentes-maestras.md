## Cómo actualizar el curso

1. Cambia la fecha solo tras revisar fuentes afectadas.
2. Conserva el hecho histórico aunque cambie el producto.
3. Marca funciones retiradas; no reescribas el pasado como si nunca hubieran existido.
4. Para un incidente, enlaza postmortem primario y registra correcciones.
5. Para cifras, guarda fecha, denominador, condiciones y versión del benchmark.
6. Ejecuta el validador de enlaces internos descrito en la raíz o usa `rg` para comprobar rutas.
